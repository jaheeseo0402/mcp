# 예비 실험: 연속호출에서만 나오는 위반이 있는가 (상태 의존적 도구 조합 퍼징 주제 검증)

판정 규칙(서재희 결정): 연속호출에서만 나오는 위반이 재현되면 새 주제로 전환, 아니면 기존 주제(L0~L4 정보 수준) 유지.

## 방법
- 서버: mcp-server-filesystem 0.6.2(old), @agent-infra/mcp-server-filesystem 1.2.29(agent). 샌드박스 폴더 W/a를 허용 폴더로 지정.
- 폴더 밖에 비밀 파일(W/secret.txt), 접두사 형제 폴더(W/a_evil), W/o를 둠. 심볼릭 링크(a/ln -> W/o)가 있는 경우와 없는 경우 둘 다 실험.
- 호출 후보 102개(심링크 포함 124개): 모든 경로 도구 x 유효/경로 이탈/접두사 형제 경로, move_file 조합.
- 오라클: 허용 폴더 밖 파일 변경(해시 비교) 또는 응답에 비밀 문자열 포함.
- 단독 호출은 호출마다 파일시스템을 초기화한 뒤 측정. "단독으로는 안전한 호출"만 골라 연속호출로 조합.

## 결과
| 서버 | 단독 위반 호출 | 2연속 조합 시험(심링크 없음/있음) | 연속호출에서만 나온 위반 | 무작위 3연속 15,000회 x 2조건 |
|---|---|---|---|---|
| old | 12 | 4,770 / 7,728 | 0 | 0 |
| agent | 12 | 4,770 / 7,728 | 0 | 0 |

단독 위반 12개는 모두 접두사 형제 폴더(a_evil) 접근이거나 `..` 경유 접근이며, 호출 하나만으로 재현됨.

## 해석
- 두 서버 모두 경로 검사가 호출마다 독립적(상태 없음)이라서 "단독은 안전, 연속에서만 위반"인 경우가 없음.
- 따라서 이 두 서버로는 새 주제(상태 의존 조합 퍼징)의 핵심 가정이 재현되지 않음 -> 기존 주제 유지.
- 한계: 도구 9~10개, 호출 후보 100여 개, 심링크 생성 도구가 없는 서버만 시험. 심링크/하드링크 생성이나 git 같은 상태 있는 도구가 있는 서버에서는 결과가 다를 수 있음(미시험).
