# 어려웠던 점과 고친 것

- **"mcp-fuzzer 비교"의 정의**: 처음에는 입력 생성만 따로 비교했다. 교수 피드백으로 모두를 같은 AFL식 틀(변이 + 커버리지 피드백)에 넣어 비교하도록 바꿨다. 진짜 AFL/AFL++는 파일·표준입력 프로그램용이라 JSON-RPC로 말하는 Node 서버에 바로 붙지 않아 재구현했고, 이것이 한계로 남는다.
- **지표 용어**: "도달률", "경계에 닿았다" 등은 논문 용어가 아니었다. 입력 검증 통과율 / 정상 실행률 / 경로 이탈 성공 / 고유 버그 유발 입력 / 신규 커버리지로 바꾸는 중.
- **지표가 다른 걸 재는 문제**: adpharm-ro에서 Random의 도달률이 높게 나온 것은 "파일 없음" 응답까지 도달로 센 탓이었다 (docs/RESULTS.md).
- **블랙박스에서는 0건**: 폴더 구조를 모르면 제안 모델도 효과가 없다. 주장을 "폴더 정보를 알 때"로 한정했다.
- **슬라이드·대본 번호 어긋남**: 대본이 15쪽부터 실제 덱과 어긋나 있어 실제 덱 기준으로 다시 만들었다.
- **실험 재현 문제**: 커버리지 수집용 preload 파일이 `type: module` package.json 때문에 로드되지 않아 `.cjs`로 바꿨다 (kit 시험 중 발견). 절대경로를 상대경로로 바꾸는 작업도 했다.
- **긴 실험이 중간에 끊김**: 백그라운드 실행이 세션 종료와 함께 죽어서, 이어 돌리기가 되도록 스크립트를 "끝난 것은 건너뜀" 방식으로 만들었다.
- **재현 환경 차이**: agent-infra 커버리지 기준선이 달랐다(약 +98). 조건 간 비교는 영향 없음.
- **크래시 측정의 한계**: 오류 문구만 보며 프로세스 종료 감지가 없다.
- **웹 도구 제한**: 일부 사이트는 직접 가져오기가 막혀 검색으로 URL을 먼저 찾아야 했다.
