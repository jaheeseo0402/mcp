## 해석 주의
1. **adpharm-ro의 "도달률" 역전 (Random 84.1 > 제안 75.1)**: 코드 버그가 아니라 지표의 성격. 도달률은 "폴더 밖 거절·형식 오류가 아닌 모든 응답"을 센다. Random은 시드를 조금만 바꿔 폴더 안에 머물고 그 입력의 54%가 "파일 없음"으로 끝나는데 이것도 도달로 센다. 제안은 일부러 폴더 밖 경로·경계값을 보내 거절이 많다. 정상 처리율(23.7 vs 15.0)이 더 의미 있는 지표. → 용어도 "입력 검증 통과율 / 정상 실행률"로 정리.
2. **고유 경로(pairs) 3~4개**는 서버 폴더의 이웃이 3개뿐이라 상한에 가깝다. 취약점 종류 수가 아니다.
3. **환경 차이**: agent-infra 커버리지는 재현 환경에서 세 조건 모두 약 +98 높게 나옴(서버 기동 시 읽는 코드량 차이로 추정). 조건 간 차이는 동일. 발표 자료에는 한 환경의 숫자만 쓴다.
4. 진짜 mcp-fuzzer 도구 그대로 실행 시 폴더 밖 성공 0 (old/agent, 개발 환경 기준). 재현자 환경 실행은 진행 예정.

## 용어 정리 (기존 문헌에 맞춤)
- 탈출 → **경로 이탈 입력** (path traversal, CWE-22/23/36)
- 경계 → **경계값 입력** (boundary value analysis: 빈 값, 4,096자, 없는 파일)
- 정상 → **유효 입력**
- 근접오답 → **준유효 입력** (semi-valid, Tsankov et al. 2013)
- "4종류를 섞는 조합"과 25% 비율은 이 연구의 설계이다.
