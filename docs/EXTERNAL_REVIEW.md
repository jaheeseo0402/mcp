# 외부 검토(다른 AI 5건)와 반영 내용 — 2026-11-23

`docs/ASK_OTHER_AI.md`(1차판)를 보내 받은 조언을 정리한다. 논문 번호는 검색으로 존재만 확인했고(ToFu arXiv 2610.13651, MCP-FSD arXiv 2610.22301) 내용 대조는 아직이다.

## 조언 요약과 처리
| 조언 | 처리 |
|---|---|
| 경로 이탈 성공을 응답이 아닌 실제 파일 접근으로 판정(오라클) | **반영**. `docs/ORACLE.md`. 응답 기반이 실제보다 약 19~33% 크게 셌음 |
| 퍼저·분석기 경로 필드 기준 불일치 수정 | **반영** (`kit/common.py`) |
| 시드 짝지은 대응표본 검정, 의사 반복 주의 | **반영** (Wilcoxon, 부트스트랩). 시드 10개 단측 최소 p=0.001이라 "p<0.001" 표기 불가 |
| 정보량 통제(같은 정보로 비교), 정보 수준별 실험 | **반영**. `docs/INFO_LEVELS.md` (L0~L4, four vs rand) |
| 폴더 이름 고정 문제, 이름 무작위화 | **반영** (3단계, `--rename`) |
| 4종 25% 고정 주장 폐기, 경로 이탈 입력이 핵심 | **반영**. 같은 정보에서 four < rand로 확인 |
| 기여를 "구조 정보 수준의 영향 실증"으로 프레이밍 | **채택 방향**. 교수님 확인 대기 |
| LLM 독립 풀 3~5개 반복, 모델명 기록, 도구 설명 포함 여부 분리 | **보류**(현재 1풀·모델명 미기입). 같은 오라클로 재측정 필요 |
| 패치 전후(취약/수정 버전) 비교, 코드 계보·서버 독립성 확인 | **미착수** |
| 새 방향 제안(도구 간 일관성, 구현 간 차등 테스트, 도구 조합) | **보류**. 모두 "신규성 미확인"이라고 답변 자체가 명시. 논문 전문 대조 전에는 방향을 바꾸지 않음 |
| 선행 연구 ToFu, MCP-FSD, VIPER-MCP, Park & Baek | 목록 수용. **전문 대조표는 미작성** |
| 새 취약점 발견 시 비공개 제보 절차 | 참고. 현재 결과는 알려진 유형(접두어 검사 우회)의 탐지 실험이며 새 CVE 주장 아님 |

## 외부 검토가 놓쳤거나 우리가 확인한 것
- 오라클을 만든 뒤 실제 확인된 위반은 목록 노출과 밖 파일 이동이 대부분이고 비밀 토큰 노출은 정보 L4에서만 나왔다(검토의 우려가 맞았음).
- 4종류 구성의 위반 수 열세는 검토가 예상하지 못한 결과였고, 그에 따라 기여를 "정보 수준의 영향"으로 옮기는 근거가 되었다.
