# genfuzz — 일반 퍼징: 구조정보 단계(L0~L3)별 AFL++ 비교 (실험 1)

구조정보 단계: L0 정보 없음(시드 1바이트) / L1 형식 이름·시그니처(시드 "TFMT") / L2 L1 + 필드 구조 사전(-x dict.txt) / L3 L2 + 유효 샘플 3개.

- `target/tinyfmt.c`: 파이프라인 검증용 타깃. 버그 5개를 구조 깊이가 다르게 일부러 심었다. 그래서 단계가 높을수록 많이 찾는 것은 설계상 당연하다. 논문 결과는 실제 프로그램으로 따로 낸다.
- `run_afl.sh 단계 초 반복번호`: AFL++ 실행. `analyze1.py`: 그래프(`exp1_time.png`, `exp1_final.png`)와 `exp1_summary.csv`.
- 지표: 전체 crash(끝 시점), 고유 crash(AFL++이 저장한 수), 서로 다른 버그(저장한 crash를 다시 실행해 [BUG n] 표시로 합침), edge, 큐 크기.
